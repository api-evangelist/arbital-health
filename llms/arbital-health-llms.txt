# Arbital Health

> Arbital Health builds the neutral third-party infrastructure for adjudicating outcomes-based
> (value-based care) contracts between payers, providers, employers, risk-bearing entities and
> point-solution vendors. Its platform centralizes risk contracts, ingests and validates claims and
> eligibility data, runs actuarial calculations (IBNR, MLR, benchmarks, attribution), predicts and
> monitors contract performance, and adjudicates settlement between the parties.

## API status

Arbital Health has **no public developer program**. There is no developer portal, no API reference,
and no machine-readable contract (no OpenAPI, AsyncAPI, GraphQL SDL, or Postman collection) at any
public URL. A real JSON API sits behind the customer platform:

- https://platform.arbitalhealth.com/api — every resource path returns `401 {"error":"Unauthorized"}`
- https://platform.arbitalhealth.com/api/health — the one anonymously readable endpoint (`200`)

Access is customer-only, brokered through an OpenID Connect tenant (PropelAuth) at
https://auth.arbitalhealth.com.
